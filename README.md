## About the project

This project is a registration website for Coding Conf, a made-up coding event. It has three pages: a home page, a registration form and a ticket page. The event date is October 26, 2026, and the location is Papine, Kgn.

The website uses HTML, CSS and JavaScript. The images and icons came with the assignment.

## How to use it

1. Open the website using the link below.
2. Click Register Now.
3. Add a photo and enter your name, email address and GitHub username.
4. Click Generate My Ticket to see your ticket.
5. You can print the ticket using the Print My Ticket button.

Use a JPG or PNG photo smaller than 500 KB. The GitHub username must start with @. If a field is missing or incorrect, a message appears below it.

## Pages and folders

- HTML/index.html - information about the event.
- HTML/login.html - the registration form.
- HTML/ticket.html - shows the ticket with the details entered.
- css/style.css - colours, spacing and page layouts.
- js/validation.js - checks the form and saves the details.
- js/ticket.js - adds the saved details to the ticket.
- assets/images - the images and icons.
- documentation - the report and screenshots.

The extra index.html in the main folder opens the home page in the HTML folder.
